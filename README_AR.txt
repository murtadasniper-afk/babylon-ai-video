بابلون AI Video — مشروع أندرويد تجريبي مع محاولة ربط توليد الفيديو

- الواجهة الأصلية محفوظة.
- أضيفت خانة رمز وصول Hugging Face وزر لمحاولة إرسال وصف إلى مزود فيديو.
- قد يفشل الاتصال بسبب تغيّر واجهة المزود أو صلاحيات الحساب أو الرصيد أو CORS داخل WebView.
- لا توجد خدمة توليد فيديو سحابية مضمونة المجانية بلا حدود. افحص الأسعار والرصيد قبل إرسال الطلب.
- لا تدخل كلمة مرور حسابك. استخدم رمز وصول محدود الصلاحيات ولا تشارك ملف APK مع الآخرين إذا خزنت فيه بياناتك.
- هذا مجلد مصدر، وليس APK مبنيًا. يتطلب بناء APK بيئة Android SDK/Gradle أو تشغيل سير عمل البناء في GitHub Actions.


ملاحظات الإصلاح:
- تم تحديث ملف GitHub Actions لتثبيت platform-tools وAndroid API 35 وBuild Tools 35.0.0 صراحةً.
- تم تعديل أمر البناء المحلي لاستخدام Gradle Wrapper بدلًا من الأمر gradle العام.
- لا يمكن ضمان نجاح البناء قبل تشغيله على GitHub؛ إذا فشل إعداد SDK مجددًا، نحتاج إلى سجل الخطأ الكامل السابق لرسالة sdkmanager.
